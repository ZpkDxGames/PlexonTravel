# PlexonTravel 3.1.1

Focused command-ownership compatibility patch for PlexonCraft.

## Changed
- PlexonTravel no longer declares or registers the top-level `/warps` command.
- The plain `/warps` label is intentionally left available for the server's custom per-world warp panel.
- `/warp [name]`, warp persistence, warp administration, the public warp API, and the internal `/ptravel warps` recovery/browser route remain intact.
- The existing `plexontravel.warps` permission is retained for internal browser compatibility.

## Compatibility
No SQLite, configuration, world-settings, RTP, void-rescue, TPA, spawn/hub, or warp-data migration is required from 3.1.0.

## Rollback
Rollback baseline: `v3.1.0` / `02e61ad9a48ef80b8bf2a6c6e886b4dd7b94c80b`.

## Certification boundary
GitHub CI verifies the exact source, distribution, tests, and Paper startup smoke. Live PlexonCraft command ownership and custom-panel behavior remain an in-game verification step.
