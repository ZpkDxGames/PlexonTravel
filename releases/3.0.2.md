# PlexonTravel 3.0.2

PlexonTravel 3.0.2 fixes the production startup regression that prevented the 3.0.x line from upgrading cleanly from an existing 2.x configuration.

## Production root cause

PlexonCraft startup evidence proved that 3.0.0 and 3.0.1 disabled during configuration validation. The affected settings were `destinations.spawn.fallback`, `destinations.hub.fallback`, and `rtp.center.mode`.

Those keys were introduced in 3.0. Existing 2.x `config.yml` files do not contain them, so they are supplied through the embedded 3.x defaults. The validator checked `ConfigurationSection.contains(path)`, which sees inherited defaults, and then read the same key through `getString(path, "")`, whose explicit method fallback bypassed the root default for a non-explicit key. The result was an empty string for all three inherited settings, causing a valid legacy configuration to be rejected before PlexonTravel could start.

3.0.2 validates the effective inherited value instead. Explicitly invalid configured values still fail closed.

## Regression and runtime proof

- Adds the exact PlexonTravel 2.0.0 configuration shape as a regression fixture.
- Tests that the three 3.x settings are absent from the persisted legacy file but resolve from embedded defaults during validation.
- Adds a real Paper startup smoke gate using Java 25, Paper `26.2.build.121-stable`, the released PlexonCore 2.0.5 JAR, the candidate PlexonTravel JAR, and the legacy 2.0.0 config fixture.
- Stable publication now requires that real Paper smoke test to pass.
- Stable releases include `PAPER_STARTUP_SMOKE.txt` alongside the JAR, SHA-256, test summary and provenance.

## Startup diagnostics

PlexonTravel now emits concise `STARTUP_PHASE` markers and a machine-readable `STARTUP_READY` marker. Managed startup failures also write `plugins/PlexonTravel/startup-failure.txt` with plugin/Paper/Java versions, the failing phase, exception type, root-cause message and timestamp. A later successful startup removes stale failure evidence. The original Paper console stack trace remains intact.

## Compatibility

- Paper: `26.2.build.121-stable`
- Java: `25`
- PlexonCore: `2.0.5` / API `2.0`
- Existing 2.x/3.x SQLite data remains unchanged.
- Existing spawn, hub, warp, back, TPA and RTP behavior is unchanged by this hotfix.
- Rollback remains `v3.0.1` while live verification is pending.

## Certification boundary

The release pipeline proves startup on an isolated real Paper server. That is CI runtime evidence, not live PlexonCraft certification. After installing 3.0.2 on PlexonCraft, perform a full service restart and verify `STARTUP_READY`, a green PlexonTravel entry in `/pl`, and successful `/plexontravel:warps` execution before marking live production PASS.
