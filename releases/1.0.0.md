# PlexonTravel 1.0.0

First Core-native PlexonCraft travel runtime for Paper 26.2 / Java 25.

## Included
- `/spawn`, `/hub`, `/back`, `/warp`, `/warps` and staging-safe `/ptravel` namespace.
- Spawn/hub destination persistence and configurable respawn policy.
- Bounded, persisted `/back` history with death/external teleport capture and natural A→B swapping.
- Admin-managed warps, per-warp permissions, 45-item paginated warp GUI and read-only-first Essentials warp migration.
- One pending travel per player, one shared warmup ticker, movement/damage/quit/death/world-change cancellation and monotonic cooldowns.
- Bounded safe-destination search with async Paper chunk preparation and final destination revalidation.
- Optional Vault fees charged only after warmup/final validation, with refund on teleport failure.
- SQLite/WAL persistence, diagnostics, backup command, public immutable API and public travel/warp events.
- Hard PlexonCore 2.0 runtime dependency and Core module registration.

## Candidate status
The GitHub artifact is release-ready code, but the production command-ownership/source audit, migration staging, 30-minute soak and Spark profile require the live PlexonCraft server. Standard command takeover therefore defaults to disabled (`migration.claim-standard-commands: false`) and the GitHub release is initially marked prerelease. After live gates pass, the same `v1.0.0` release can be promoted without rebuilding the JAR.
